# Word choices

This file gives examples of words that ASD-STE100 does not approve, and the
words that you use in their place. This is not the full Dictionary. ASD owns
the copyright of the full Dictionary. Get the specification at no cost from
https://asd-ste100.org.

If a word is not in this file, and you are not sure, tell the user that the
word needs a check against the official Dictionary.

## Verbs

| Do not use | Use |
|---|---|
| accomplish, execute, perform | do |
| acquire, obtain, procure | get |
| adhere to, comply with | obey |
| ascertain, determine | find, make sure |
| assist | help |
| attempt | try |
| cease, terminate, discontinue | stop |
| commence, initiate | start |
| conduct (a test) | do (a test) |
| depress (a button) | push |
| desire | want |
| endeavor | try |
| ensure | make sure |
| inspect | do a check of |
| facilitate | help, make easy |
| light (a lamp) | come on |
| indicate | show |
| locate | find |
| modify | change |
| observe | look at, see |
| permit | let |
| purchase | get |
| rectify, remedy | correct, repair |
| replenish | fill |
| require | be necessary |
| retain | keep |
| utilize | use |
| verify | make sure, do a check of |

## Nouns

| Do not use | Use |
|---|---|
| aperture | hole |
| assistance | aid |
| commencement | start |
| illumination | light |
| fault | malfunction |
| portion | part |
| remainder | the other part |
| termination | end |
| utilization | use |
| vicinity | area |

## Adjectives and adverbs

| Do not use | Use |
|---|---|
| adequate | sufficient |
| about | approximately |
| additional | more |
| numerous, multiple | many |
| optimum | best |
| earlier | previous |
| main | primary |
| rapidly | quickly |
| next | subsequent |

## Phrases

| Do not use | Use |
|---|---|
| a number of | some, many |
| now | at this time |
| due to the fact that | because |
| for the purpose of | to, for |
| as in | in accordance with |
| in conjunction with | with |
| in order to | to |
| in the event that | if |
| in the vicinity of | near |
| is capable of | can |
| it is necessary to | you must |
| prior to | before |
| subsequent to | after |
| with regard to | about |

## Words with one approved meaning

| Word | Approved meaning | Do not use it for |
|---|---|---|
| follow | to come after | to obey |
| about | concerned with | approximately |
| close | to shut | near |
| only | no more than | alone |
| right | the opposite of left | correct |
| test | a noun (do a test) | a verb (test the pump) |
